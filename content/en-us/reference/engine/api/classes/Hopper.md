# Hopper

Hopper is the original name of the StarterPack service.

**Inherits from:** `Class.Instance` > `Class.Object`

**Tags:** [NotCreatable] [Service] [Deprecated]

## Description

If this service is ever instantiated, it moves all of its children into the
`Class.StarterPack` and then deletes itself.

> **Deprecated:** `Class.Hopper` has been replaced by `Class.StarterPack` and should not be used
in new work.
