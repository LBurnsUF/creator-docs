# ReflectionMetadataYieldFunctions

Acts as a `Class.Folder` containing information about yielding functions for a
`Class.ReflectionMetadataClass`, and should be parented to it.
`Class.ReflectionMetadataMember|ReflectionMetadataMembers` that are parented
to this object will be perceived as yielding functions under the class this is
parented to.

**Inherits from:** `Class.Instance` > `Class.Object`
