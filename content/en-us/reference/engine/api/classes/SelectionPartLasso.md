# SelectionPartLasso

An instance used to display a "lasso" between a `Class.Humanoid` Torso and a
`Class.BasePart`.

**Inherits from:** `Class.SelectionLasso` > `Class.GuiBase3d` > `Class.GuiBase` > `Class.Instance` > `Class.Object`

**Tags:** [Deprecated]

## Description

An instance used to display a "lasso" between a `Class.Humanoid` Torso and a
`Class.BasePart`. It should be noted that the `Class.GuiBase3d.Transparency`
property doesn't currently work.

> **Deprecated:** SelectionPartLasso has been deprecated. Developers are advised to use the
`Class.Beam` object instead.
