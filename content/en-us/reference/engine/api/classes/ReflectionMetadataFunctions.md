# ReflectionMetadataFunctions

Acts as a `Class.Folder` containing information about functions for a
`Class.ReflectionMetadataClass`, and should be parented to it.
`Class.ReflectionMetadataMember|ReflectionMetadataMembers` that are parented
to this object will be perceived as functions under the class this is parented
to.

**Inherits from:** `Class.Instance` > `Class.Object`
