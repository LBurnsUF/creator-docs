# LuaSourceContainer

The base class for all objects which contain Luau code.

**Inherits from:** `Class.Instance` > `Class.Object`

**Tags:** [NotCreatable] [NotBrowsable]

## Description

The base class for all objects which contain Luau code. `Class.Script`,
`Class.LocalScript`, and `Class.ModuleScript` all inherit from
**LuaSourceContainer**.
