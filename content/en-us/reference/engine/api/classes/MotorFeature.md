# MotorFeature

**Inherits from:** `Class.Feature` > `Class.Instance` > `Class.Object`

**Tags:** [Deprecated]

## Description

A MotorFeature is an unused type of surface joint. It can be connected to a
`Class.Hole` object by using a `Class.VelocityMotor`.

> **Deprecated:** A MotorFeature is an unused type of surface joint. It should not be used for
new work.
