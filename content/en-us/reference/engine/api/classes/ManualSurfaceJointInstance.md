# ManualSurfaceJointInstance

ManualSurfaceJointInstance is the base class for `Class.ManualGlue` and
`Class.ManualWeld`.

**Inherits from:** `Class.JointInstance` > `Class.Instance` > `Class.Object`

**Tags:** [NotCreatable] [Deprecated]

## Description

The ManualSurfaceJointInstance is the base class for `Class.ManualGlue`. This
instance (when created) also used to cause the server to crash, however this
behavior has since been fixed.
