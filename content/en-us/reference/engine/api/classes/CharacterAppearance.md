# CharacterAppearance

The base class for objects that change the character's appearance, such as the
`Class.BodyColors`, `Class.CharacterMesh`, `Class.ShirtGraphic`, `Class.Pants`
and `Class.Shirt` objects.

**Inherits from:** `Class.Instance` > `Class.Object`

**Tags:** [NotCreatable]

## Description

Base class for objects that change a character's appearance.
