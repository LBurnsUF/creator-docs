# `Enum.Axis`

One of the 3D axes.

The Axis Enum represents the X, Y and Z axes. Primarily this Enum is used with
`Class.ArcHandles` and `Class.Handles`.

The `Enum.Axis` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.Axis.X` | 0 | The X axis. |
| `Enum.Axis.Y` | 1 | The Y axis. |
| `Enum.Axis.Z` | 2 | The Z axis. |
