# `Enum.ThrottlingPriority`

Amount of throttling to apply.

Controls the amount of throttling under the `Class.HttpRbxApiService`.

The `Enum.ThrottlingPriority` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.ThrottlingPriority.Default` | 0 | Standard throttling. |
| `Enum.ThrottlingPriority.ElevatedOnServer` | 1 | Less throttling if on the server. |
| `Enum.ThrottlingPriority.Extreme` | 2 | No throttling, absolutely no exceptions. |
