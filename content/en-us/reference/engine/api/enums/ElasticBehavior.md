# `Enum.ElasticBehavior`

This enum is used by `Class.ScrollingFrame.ElasticBehavior` to control when
elastic scrolling is active on touch‑enabled devices.

This enum is used by `Class.ScrollingFrame.ElasticBehavior` to control when
elastic scrolling is active on touch‑enabled devices.

The `Enum.ElasticBehavior` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.ElasticBehavior.WhenScrollable` | 0 | Scrolling is elastic when there is content to be scrolled to. |
| `Enum.ElasticBehavior.Always` | 1 | Scrolling is always elastic, even when there isn't content available to scroll to. |
| `Enum.ElasticBehavior.Never` | 2 | Scrolling is never elastic and the canvas will never scroll beyond its bounds. |
