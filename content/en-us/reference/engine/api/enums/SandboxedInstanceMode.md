# `Enum.SandboxedInstanceMode`

Controls whether sandboxed instance mode (script capabilities) is enabled.

Determines whether sandboxed instance mode, which lets you use script
capabilities, is active. This enum is used by
`Class.Workspace.SandboxedInstanceMode`.

The `Enum.SandboxedInstanceMode` enum has 2 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.SandboxedInstanceMode.Default` | 0 | Uses the engine-default sandboxed instance state. |
| `Enum.SandboxedInstanceMode.Experimental` | 1 | Sandboxed instance mode is enabled. |
