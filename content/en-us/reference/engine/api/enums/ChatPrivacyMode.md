# `Enum.ChatPrivacyMode`

Internally controls the user's chat privacy settings.

The `Enum.ChatPrivacyMode` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.ChatPrivacyMode.AllUsers` | 0 | A player can chat with all users in a game. |
| `Enum.ChatPrivacyMode.NoOne` | 1 | A player cannot chat with any other users in a game. |
| `Enum.ChatPrivacyMode.Friends` | 2 | A player can only chat with users in a game that are on their friends list. |
