# `Enum.ChatVersion`

Determines whether `Class.TextChatService` should be fully enabled or to allow
the legacy system.

Determines whether `Class.TextChatService` should be fully enabled or to allow
the legacy system.

`Class.TextChatService.ChatVersion` is not scriptable and must be set in
Studio.

The `Enum.ChatVersion` enum has 2 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.ChatVersion.LegacyChatService` | 0 | Enables the legacy chat system. |
| `Enum.ChatVersion.TextChatService` | 1 | Enables `Class.TextChatService` chat and prevents legacy chat system behavior. |
