# `Enum.MouseBehavior`

Sets the user's mouse behavior.

Used with the `Class.UserInputService.MouseBehavior` property of
`Class.UserInputService` to set how the user's mouse behaves.

The `Enum.MouseBehavior` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.MouseBehavior.Default` | 0 | The mouse moves freely around the user's screen. |
| `Enum.MouseBehavior.LockCenter` | 1 | The mouse is locked and cannot move from the center of the user's screen. |
| `Enum.MouseBehavior.LockCurrentPosition` | 2 | The mouse is locked and cannot move from its current position on the user's screen at the time of lo |
