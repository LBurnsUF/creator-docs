# `Enum.ProductPurchaseDecision`

The `ProductPurchaseDecisionEnum` works with `Class.MarketplaceService` to
indicate the status of the sale of developer products.

The `ProductPurchaseDecisionEnum` is used to work with
`Class.MarketplaceService`, and the sale of developer products.

The `Enum.ProductPurchaseDecision` enum has 2 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.ProductPurchaseDecision.NotProcessedYet` | 0 | The purchase request has been sent but not yet processed. |
| `Enum.ProductPurchaseDecision.PurchaseGranted` | 1 | The purchase has been processed and granted to the user who initiated the purchase request. |
