# `Enum.ChatColor`

Describes the chat color.

The **ChatColor** enum is used to change the color of a chat using
`Class.Chat`.

The `Enum.ChatColor` enum has 4 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.ChatColor.Blue` | 0 | Blue chat color. |
| `Enum.ChatColor.Green` | 1 | Green chat color. |
| `Enum.ChatColor.Red` | 2 | Red chat color. |
| `Enum.ChatColor.White` | 3 | White chat color. |
