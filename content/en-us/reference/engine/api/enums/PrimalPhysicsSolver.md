# `Enum.PrimalPhysicsSolver`

Controls whether the experimental Primal Physics Solver is enabled.

An experimental constraint solver that can improve accuracy in complex setups.
This enum is used by `Class.Workspace.PrimalPhysicsSolver`.

The `Enum.PrimalPhysicsSolver` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.PrimalPhysicsSolver.Default` | 0 | Uses the engine-default physics solver state. |
| `Enum.PrimalPhysicsSolver.Experimental` | 1 | The experimental Primal Physics Solver is enabled. |
| `Enum.PrimalPhysicsSolver.Disabled` | 2 | The Primal Physics Solver is disabled. |
