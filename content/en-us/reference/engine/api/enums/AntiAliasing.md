# `Enum.AntiAliasing`

Determines whether anti-aliasing is applied when drawing on the instance.

Determines whether anti-aliasing is applied when drawing on the instance.

The `Enum.AntiAliasing` enum has 2 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.AntiAliasing.Disabled` | 0 | Disables anti-aliasing, resulting in hard edges. |
| `Enum.AntiAliasing.Enabled` | 1 | Enables anti-aliasing, resulting in soft edges. |
