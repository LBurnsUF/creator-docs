# `Enum.GearGenreSetting`

The GearGenreSetting Enum sets what types of gear are allowed in a place.

The `Enum.GearGenreSetting` enum has 2 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.GearGenreSetting.AllGenres` | 0 | All gear genres are allowed. |
| `Enum.GearGenreSetting.MatchingGenreOnly` | 1 | Only gear genres matching the allowed genres specified in a place's configuration settings. |
