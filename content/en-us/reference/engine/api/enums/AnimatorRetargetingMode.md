# `Enum.AnimatorRetargetingMode`

Animation Retargeting setting.

The AnimatorRetargetingMode Enum describes the setting for Animation
Retargeting. Retargeting adapts animations to various character rigs based on
their proportions.

The `Enum.AnimatorRetargetingMode` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.AnimatorRetargetingMode.Default` | 0 | Retargeting in default state, opt-in initially but subject to change. |
| `Enum.AnimatorRetargetingMode.Disabled` | 1 | Retargeting disabled. |
| `Enum.AnimatorRetargetingMode.Enabled` | 2 | Retargeting enabled. |
