# `Enum.FunctionalTestResult`

Status of a single functional test run.

Represents the outcome of a single functional test run.

The `Enum.FunctionalTestResult` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.FunctionalTestResult.Passed` | 0 | The test run was successful. |
| `Enum.FunctionalTestResult.Warning` | 1 | The test run is potentially unstable. |
| `Enum.FunctionalTestResult.Error` | 2 | The test run failed. |
