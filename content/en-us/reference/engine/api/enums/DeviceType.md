# `Enum.DeviceType`

Device category of the client.

The **DeviceType** enum is used to determine the category of devices that a
client belongs to.

The `Enum.DeviceType` enum has 5 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.DeviceType.Unknown` | 0 | The client is an unknown device. |
| `Enum.DeviceType.Desktop` | 1 | The client is a desktop device. |
| `Enum.DeviceType.Tablet` | 2 | The client is a tablet device. |
| `Enum.DeviceType.Phone` | 3 | The client is a phone device. |
| `Enum.DeviceType.TV` | 4 |  |
