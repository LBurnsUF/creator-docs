# `Enum.TextYAlignment`

Determines vertical alignment of text.

Determines vertical alignment of text.

Used by `Class.TextLabel.TextYAlignment|TextLabel`,
`Class.TextButton.TextYAlignment|TextButton`, and
`Class.TextBox.TextYAlignment|TextBox`.

The `Enum.TextYAlignment` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.TextYAlignment.Top` | 0 | Alignment starts at the top of the GUI object. |
| `Enum.TextYAlignment.Center` | 1 | Aligned starts at the center of the GUI object and spreads equally toward the top and bottom. |
| `Enum.TextYAlignment.Bottom` | 2 | Alignment starts at the bottom of the GUI object. |
