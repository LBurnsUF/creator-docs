# `Enum.GuiState`

The `Enum.GuiState` enum has 4 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.GuiState.Idle` | 0 | The GUI currently has no state. |
| `Enum.GuiState.Hover` | 1 | The GUI is being hovered over by the user. |
| `Enum.GuiState.Press` | 2 | The GUI is being pressed/held down by the user. |
| `Enum.GuiState.NonInteractable` | 3 | The GUI cannot be interacted with and therefore has no states. |
