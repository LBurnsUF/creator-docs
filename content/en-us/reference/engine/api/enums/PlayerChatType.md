# `Enum.PlayerChatType`

Determines the style of a chat message.

Used by Roblox's Chat to determine the style of a chat message. If you want to
check for this kind of stuff, see `Class.Player.Chatted`.

The `Enum.PlayerChatType` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.PlayerChatType.All` | 0 | A global message that everyone can receive. |
| `Enum.PlayerChatType.Team` | 1 | A team message only players in the same team can receive. |
| `Enum.PlayerChatType.Whisper` | 2 | A whispered message only the person it's whispered to can receive. |
