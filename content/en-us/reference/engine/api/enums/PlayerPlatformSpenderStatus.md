# `Enum.PlayerPlatformSpenderStatus`

Describes a player's platform-wide spender status bucket.

The `PlayerPlatformSpenderStatus` enum describes a player's platform-wide
spender status bucket.

The `Enum.PlayerPlatformSpenderStatus` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.PlayerPlatformSpenderStatus.Unknown` | 0 | Segment data is unavailable. |
| `Enum.PlayerPlatformSpenderStatus.Active` | 1 | The player is an active platform spender. |
| `Enum.PlayerPlatformSpenderStatus.OtherPayer` | 2 | The player is not an active platform spender, including players who have never spent. |
