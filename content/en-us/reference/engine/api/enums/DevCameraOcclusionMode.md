# `Enum.DevCameraOcclusionMode`

Determines how the default camera handles objects that are in-between the
camera and the camera subject.

Determines how the default camera handles objects that are in-between the
camera and the camera subject.

The `Enum.DevCameraOcclusionMode` enum has 2 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.DevCameraOcclusionMode.Zoom` | 0 | The camera zooms in until there is nothing between it and its subject. |
| `Enum.DevCameraOcclusionMode.Invisicam` | 1 | Any objects between the camera and its subject become translucent locally. |
