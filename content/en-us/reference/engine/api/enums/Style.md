# `Enum.Style`

The Style Enum is used to set what style of supports the `Class.TrussPart`
has.

The Style Enum is used to set what style of supports the `Class.TrussPart`
has.

The `Enum.Style` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.Style.AlternatingSupports` | 0 | Truss beams contain alternating supports. |
| `Enum.Style.BridgeStyleSupports` | 1 | Truss beams contain bridge style supports. |
| `Enum.Style.NoSupports` | 2 | Truss beams do not contain supports. |
