# `Enum.InviteState`

Describes a player's call invite state.

This enum describes a player's call invite state. See
`Class.SocialService.CallInviteStateChanged` for details.

The `Enum.InviteState` enum has 4 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.InviteState.Placed` | 0 | Call invite was placed. |
| `Enum.InviteState.Accepted` | 1 | Call invite was accepted. |
| `Enum.InviteState.Declined` | 2 | Call invite was declined. |
| `Enum.InviteState.Missed` | 3 | Call invite was missed. |
