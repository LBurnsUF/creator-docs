# `Enum.VirtualCursorMode`

Enables Virtual Cursor mode within an experience.

Enables Virtual Cursor mode within an experience. By default, this property is
disabled.

The `Enum.VirtualCursorMode` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.VirtualCursorMode.Default` | 0 | The Virtual Cursor is in the default state. |
| `Enum.VirtualCursorMode.Disabled` | 1 | The Virtual Cursor is disabled. |
| `Enum.VirtualCursorMode.Enabled` | 2 | The Virtual Cursor is enabled. |
