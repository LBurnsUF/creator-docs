# `Enum.SizeConstraint`

Used to constrain the scale of a GUI object.

Used to constrain the scale of a GUI object.

The `Enum.SizeConstraint` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.SizeConstraint.RelativeXY` | 0 | The scale of X and Y are independent. |
| `Enum.SizeConstraint.RelativeXX` | 1 | The scale of X is shared with Y. |
| `Enum.SizeConstraint.RelativeYY` | 2 | The scale of Y is shared with X. |
