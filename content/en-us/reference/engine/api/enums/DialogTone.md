# `Enum.DialogTone`

Sets the `Class.Dialog.Tone` of a `Class.Dialog` object, which influences how
the dialog appears.

Sets the `Class.Dialog.Tone` of a `Class.Dialog` object, which influences how
the dialog appears.

The `Enum.DialogTone` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.DialogTone.Neutral` | 0 | Causes the dialog to have a blue bar on its left-hand side. |
| `Enum.DialogTone.Friendly` | 1 | Causes the dialog to have a green bar on its left-hand side. |
| `Enum.DialogTone.Enemy` | 2 | Causes the dialog to have a red bar on its left-hand side. |
