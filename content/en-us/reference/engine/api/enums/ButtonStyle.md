# `Enum.ButtonStyle`

Used by `Class.GuiButton.Style` to set a special hardcoded appearance.

Used by `Class.GuiButton.Style` to set a special hardcoded appearance.

These should generally be avoided in favor of setting other appearance
properties, but they can be useful for wireframing.

Despite the Roblox naming, these are not used by any official Roblox UI.

The `Enum.ButtonStyle` enum has 6 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.ButtonStyle.Custom` | 0 | The button will respect the `Class.GuiObject.BorderColor3` and `Class.GuiObject.BackgroundColor3` pr |
| `Enum.ButtonStyle.RobloxButtonDefault` | 1 | A black background with a red border, and rounded corners. |
| `Enum.ButtonStyle.RobloxButton` | 2 | A black background with a grey border, and rounded corners. |
| `Enum.ButtonStyle.RobloxRoundButton` | 3 | A grey background with rounded corners, and a slight drop shadow. |
| `Enum.ButtonStyle.RobloxRoundDefaultButton` | 4 | A blue background with rounded corners, and a slight drop shadow. |
| `Enum.ButtonStyle.RobloxRoundDropdownButton` | 5 | A white background with a thin grey border, rounded corners, and a slight drop shadow. |
