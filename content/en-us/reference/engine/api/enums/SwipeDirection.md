# `Enum.SwipeDirection`

The direction that a user is swiping on their touch screen.

The SwipeDirection Enum represents the direction in which a user swipes on a
`Class.UserInputService.TouchEnabled` device.

The `Class.GuiObject.TouchSwipe` and `Class.UserInputService.TouchSwipe`
events pass this enum as an argument.

The `Enum.SwipeDirection` enum has 5 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.SwipeDirection.Right` | 0 | The user swiped right. |
| `Enum.SwipeDirection.Left` | 1 | The user swiped left. |
| `Enum.SwipeDirection.Up` | 2 | The user swiped up. |
| `Enum.SwipeDirection.Down` | 3 | The user swiped down. |
| `Enum.SwipeDirection.None` | 4 | The user did not swipe in a certain direction. |
