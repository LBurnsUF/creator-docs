# `Enum.PartType`

Controls the `Class.Part.Shape` of an object.

The **PartType** enum controls the `Class.Part.Shape|Shape` of a `Class.Part`.

The `Enum.PartType` enum has 5 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.PartType.Ball` | 0 | A spherical shape. |
| `Enum.PartType.Block` | 1 | A block shape. |
| `Enum.PartType.Cylinder` | 2 | A cylinder shape oriented along the **X** axis. |
| `Enum.PartType.Wedge` | 3 | A wedge shape with a slope on one side. |
| `Enum.PartType.CornerWedge` | 4 | A wedge shape with slopes on two sides. |
