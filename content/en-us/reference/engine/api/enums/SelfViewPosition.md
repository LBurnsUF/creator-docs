# `Enum.SelfViewPosition`

Defines the screen location of the current player's self view.

This enum defines the screen location of the current player's self view, used
in conjunction with `Class.SocialService:ShowSelfView()` for example.

The `Enum.SelfViewPosition` enum has 5 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.SelfViewPosition.LastPosition` | 0 | The position of the self view when it was last closed. |
| `Enum.SelfViewPosition.TopLeft` | 1 | Top-left corner of the screen, with slight padding from the top and left edges. |
| `Enum.SelfViewPosition.TopRight` | 2 | Top-right corner of the screen, with slight padding from the top and right edges. |
| `Enum.SelfViewPosition.BottomLeft` | 3 | Bottom-left corner of the screen, with slight padding from the bottom and left edges. |
| `Enum.SelfViewPosition.BottomRight` | 4 | Bottom-right corner of the screen, with slight padding from the bottom and right edges. |
