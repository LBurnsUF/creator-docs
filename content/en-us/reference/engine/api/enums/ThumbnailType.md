# `Enum.ThumbnailType`

Describes the type of user thumbnail that should be returned by
GetUserThumbnailAsync.

The `Enum.ThumbnailType` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.ThumbnailType.HeadShot` | 0 | The returned thumbnail shows just the headshot (head and up) of the user's avatar. |
| `Enum.ThumbnailType.AvatarBust` | 1 | The returned thumbnail shows the bust (chest up) of the user's avatar. |
| `Enum.ThumbnailType.AvatarThumbnail` | 2 | The returned thumbnail shows the entire body of the user's avatar. |
