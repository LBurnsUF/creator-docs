# `Enum.ResamplerMode`

Determines the image filtering used.

Determines the image filtering used.

The `Enum.ResamplerMode` enum has 2 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.ResamplerMode.Default` | 0 | Bilinear filtering of the four near pixels in the image. |
| `Enum.ResamplerMode.Pixelated` | 1 | Nearest neighbor filtering of the closest pixel in the image. |
