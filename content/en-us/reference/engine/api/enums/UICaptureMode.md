# `Enum.UICaptureMode`

Used to determine what UI elements should be captured with
`Class.CaptureService`.

The `Enum.UICaptureMode` enum has 2 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.UICaptureMode.All` | 0 | Capture all UI elements. |
| `Enum.UICaptureMode.None` | 1 | Capture no UI elements. |
