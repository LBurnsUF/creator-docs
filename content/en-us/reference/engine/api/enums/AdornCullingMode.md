# `Enum.AdornCullingMode`

Culling method used for adornments.

Used by `Class.HandleAdornment` to determine how it is culled.

The `Enum.AdornCullingMode` enum has 2 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.AdornCullingMode.Automatic` | 0 | Automatically culls adornment based on distance. |
| `Enum.AdornCullingMode.Never` | 1 | Never culls adornment. Adornment is always visible. |
