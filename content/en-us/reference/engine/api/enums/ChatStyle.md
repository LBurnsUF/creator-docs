# `Enum.ChatStyle`

The ChatStyle Enum is used to set the style of `Class.Chat` used in a game via
the `Class.Players:SetChatStyle()` method.

The ChatStyle Enum is used to set the style of `Class.Chat` used in a game via
the `Class.Players:SetChatStyle()` method.

The `Enum.ChatStyle` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.ChatStyle.Classic` | 0 | Displays chats in the chat user interface at the top-left corner of the screen. |
| `Enum.ChatStyle.Bubble` | 1 | Displays chats in a bubble above the sender's head. |
| `Enum.ChatStyle.ClassicAndBubble` | 2 | Has the effects of Classic and Bubble combined. |
