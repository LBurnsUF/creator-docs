# `Enum.ChatMode`

Controls the methods of communication available to a player.

The `Enum.ChatMode` enum has 2 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.ChatMode.Menu` | 0 | The player is restricted to chatting via a menu of chat messages. |
| `Enum.ChatMode.TextAndMenu` | 1 | A player can chat via custom text messages and a menu of chat messages. |
