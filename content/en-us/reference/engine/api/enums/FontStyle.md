# `Enum.FontStyle`

Describes whether a `Datatype.Font` style is normal or italic.

Describes whether a `Datatype.Font` style is normal or italic. Used by
`Datatype.Font.Style`.

The `Enum.FontStyle` enum has 2 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.FontStyle.Normal` | 0 | The text renders normally with this font. |
| `Enum.FontStyle.Italic` | 1 | The text renders italic with this font. |
