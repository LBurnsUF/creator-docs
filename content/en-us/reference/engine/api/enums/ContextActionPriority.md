# `Enum.ContextActionPriority`

Describes the priority of a context action.

The ContextActionPriority is used to set the priority of a context action.
This priority is used to determine context action order.

The `Enum.ContextActionPriority` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.ContextActionPriority.Low` | 1000 | Low priority. |
| `Enum.ContextActionPriority.Medium` | 2000 | Medium priority. |
| `Enum.ContextActionPriority.High` | 3000 | High priority. |
