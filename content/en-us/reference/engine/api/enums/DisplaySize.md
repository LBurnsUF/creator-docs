# `Enum.DisplaySize`

This enum is used with `Class.GuiService.ViewportDisplaySize` to indicate the
internally-categorized rendering size of the viewport.

This enum is used with `Class.GuiService.ViewportDisplaySize` to indicate the
internally-categorized rendering size of the viewport.

The `Enum.DisplaySize` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.DisplaySize.Small` | 0 | Viewport is categorized as small. Applies to most tablet/mobile/handheld devices. |
| `Enum.DisplaySize.Medium` | 1 | Viewport is categorized as medium. Applies to most laptops and monitors. |
| `Enum.DisplaySize.Large` | 2 | Viewport is categorized as large. Applies to most TVs or larger. |
