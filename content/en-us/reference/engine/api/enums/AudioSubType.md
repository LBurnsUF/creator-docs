# `Enum.AudioSubType`

The categorization of an audio asset.

The categorization of an audio asset between music and sound effects. This
categorization is used for filtering audio in `Class.AudioSearchParams`.

The `Enum.AudioSubType` enum has 2 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.AudioSubType.Music` | 1 | Represents an asset which contains music. |
| `Enum.AudioSubType.SoundEffect` | 2 | Represents an asset which is a sound effect. |
