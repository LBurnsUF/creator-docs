# `Enum.CustomCameraMode`

Changes the player's camera mode.

Changes the player's camera mode.

The `Enum.CustomCameraMode` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.CustomCameraMode.Default` | 0 | The default camera mode is classic. |
| `Enum.CustomCameraMode.Classic` | 1 | Camera tracks the player but will not automatically rotate if the player walks left or right. |
| `Enum.CustomCameraMode.Follow` | 2 | Camera tracks the player and automatically rotates if the player walks left or right. |
