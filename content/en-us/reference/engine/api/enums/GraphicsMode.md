# `Enum.GraphicsMode`

Used to set the graphics API that Roblox uses to render the game.

Used to set the graphics API that Roblox uses to render the game.

The `Enum.GraphicsMode` enum has 6 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.GraphicsMode.Automatic` | 1 | Roblox will automatically decide what graphics mode to use, depending on what best suits your device |
| `Enum.GraphicsMode.Direct3D11` | 2 | Direct3D Version 11 (Microsoft). |
| `Enum.GraphicsMode.OpenGL` | 4 | OpenGL (Khronos Group). |
| `Enum.GraphicsMode.Metal` | 5 | Metal (Apple). |
| `Enum.GraphicsMode.Vulkan` | 6 | Vulkan (Khronos Group). |
| `Enum.GraphicsMode.NoGraphics` | 9 | Game will not be rendered, and instead a _Diagnostics_ window is rendered on screen. |
