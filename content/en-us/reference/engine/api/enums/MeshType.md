# `Enum.MeshType`

The MeshType Enum is used to set what type of mesh the `Class.SpecialMesh` is.

The MeshType Enum is used to set what type of mesh the `Class.SpecialMesh` is.

The `Enum.MeshType` enum has 12 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.MeshType.Head` | 0 | The mesh is the default `Class.Humanoid` head mesh. |
| `Enum.MeshType.Torso` | 1 | The mesh is the default Humanoid torso mesh. |
| `Enum.MeshType.Wedge` | 2 | The mesh is a wedge. |
| `Enum.MeshType.Sphere` | 3 | The mesh is a sphere. |
| `Enum.MeshType.Cylinder` | 4 | The mesh is a cylinder. |
| `Enum.MeshType.FileMesh` | 5 | The mesh is determined by the Roblox mesh asset ID provided. |
| `Enum.MeshType.Brick` | 6 | The mesh is a brick (just like the shape of a default `Class.BasePart`). |
| `Enum.MeshType.Prism` | 7 | The mesh is a prism. |
| `Enum.MeshType.Pyramid` | 8 | The mesh is a pyramid. |
| `Enum.MeshType.ParallelRamp` | 9 | The mesh is a parallel ramp. |
| `Enum.MeshType.RightAngleRamp` | 10 | The mesh is a right angle ramp. |
| `Enum.MeshType.CornerWedge` | 11 | The mesh is a corner wedge. |
