# `Enum.ImageAlphaType`

Enum for determining if the alpha or color is locked while combining two
images.

Enum for determining if the alpha or color is locked while combining two
images.

The `Enum.ImageAlphaType` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.ImageAlphaType.Default` | 1 | The default behavior in which neither color nor alpha values are locked. |
| `Enum.ImageAlphaType.LockCanvasAlpha` | 2 | The alpha values of the image will not be modified. |
| `Enum.ImageAlphaType.LockCanvasColor` | 3 | The color values of the image will not be modified. |
