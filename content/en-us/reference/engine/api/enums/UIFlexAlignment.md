# `Enum.UIFlexAlignment`

in the parent container.

horizontal space in a `Class.UIListLayout.HorizontalFlex|HorizontalFlex`
layout or vertical space in a `Class.UIListLayout.VerticalFlex|VerticalFlex`
layout.
