# `Enum.EasingDirection`

Enum used with `Datatype.TweenInfo.new()` to control the direction
`Class.Tween|Tweens` play in.

These enum values are passed to `Datatype.TweenInfo.new()` to control the
direction `Class.Tween|Tweens` play in.

The `Enum.EasingDirection` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.EasingDirection.In` | 0 | The easing style is applied in a forward direction. |
| `Enum.EasingDirection.Out` | 1 | The easing style is applied in a reverse direction. |
| `Enum.EasingDirection.InOut` | 2 | The easing style is applied forward for the first half and in reverse for the second half. |
