# `Enum.HumanoidRigType`

Describes whether or not a character is using the new R15 rig, or the legacy
R6 rig.

Describes whether or not a character is using the new R15 rig, or the legacy
R6 rig. This is the type returned by Humanoid's RigType property, which
indicates whether the Humanoid is R6 or R15.

The `Enum.HumanoidRigType` enum has 2 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.HumanoidRigType.R6` | 0 | Indicates that a character is using the legacy R6 rig. |
| `Enum.HumanoidRigType.R15` | 1 | Indicates that a character is using the new R15 rig. |
