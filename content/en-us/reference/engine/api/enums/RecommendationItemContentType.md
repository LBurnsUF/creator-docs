# `Enum.RecommendationItemContentType`

This enum describes the content type of the recommendation item. It is
designed to be generic.

The `Enum.RecommendationItemContentType` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.RecommendationItemContentType.Static` | 0 | The item is static, such as an image. |
| `Enum.RecommendationItemContentType.Dynamic` | 1 | The item is dynamic; for example, it is a video. |
| `Enum.RecommendationItemContentType.Interactive` | 2 | The item is interactive, such as a 3D model or a mini-game. |
