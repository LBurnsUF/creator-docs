# `Enum.TextXAlignment`

Determines horizontal alignment of text.

Determines horizontal alignment of text.

Used by `Class.TextLabel.TextXAlignment|TextLabel`,
`Class.TextButton.TextXAlignment|TextButton`, and
`Class.TextBox.TextXAlignment|TextBox`.

The `Enum.TextXAlignment` enum has 3 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.TextXAlignment.Left` | 0 | Alignment starts at the left side of the GUI object. |
| `Enum.TextXAlignment.Right` | 1 | Alignment starts at the right side of the GUI object. |
| `Enum.TextXAlignment.Center` | 2 | Aligned starts at the center of the GUI object and spreads equally left and right. |
