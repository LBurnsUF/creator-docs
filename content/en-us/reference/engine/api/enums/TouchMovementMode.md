# `Enum.TouchMovementMode`

The movement mode used by a client with a TouchEnabled device.

The TouchMovementMode Enum is used to change the movement controller on Roblox
Mobile.

The `Enum.TouchMovementMode` enum has 6 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.TouchMovementMode.Default` | 0 | The default movement controller. |
| `Enum.TouchMovementMode.Thumbstick` | 1 | Change the movement controller to the classic thumbstick. |
| `Enum.TouchMovementMode.DPad` | 2 | Change the movement controller to the DPad. |
| `Enum.TouchMovementMode.Thumbpad` | 3 | Change the movement controller to the thumbpad. |
| `Enum.TouchMovementMode.ClickToMove` | 4 | Change the movement controller to click to move. |
| `Enum.TouchMovementMode.DynamicThumbstick` | 5 | Change the movement controller to the dynamic thumbstick. |
