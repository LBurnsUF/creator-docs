# `Enum.R15CollisionType`

Collision behavior type for a R15 character.

Internal enum used to save the collision behavior setting for R15 characters.

The `Enum.R15CollisionType` enum has 2 item(s).

| Name | Value | Description |
|------|-------|-------------|
| `Enum.R15CollisionType.OuterBox` | 0 | Dynamically sized collision boxes based on mesh sizes. |
| `Enum.R15CollisionType.InnerBox` | 1 | Fixed size collision boxes, similar to the classic avatar collision. |
