Cloud API resource group with 1 endpoint(s).

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/v1/batch` | Returns a list of thumbnails with varying types and sizes [STABLE] |

### `POST` `/v1/batch`

**Stability:** STABLE

**Parameters:**

- `Roblox-Place-Id` (header, integer) - (optional) placeid

**Request Body:** List of ThumbnailBatchRequest objects, may contain the following request types:
            1. Avatar
            2. AvatarHeadShot
            3. GameIcon
            4. BadgeIcon
            5.

**Responses:**

- `200` - OK
- `400` - 1: There are too many requested Ids. 2: The requested image format is invalid. Please see documenta
- `403` - 9: User not authorized to use AutoGenerated or ForceAutoGenerated return policies.
