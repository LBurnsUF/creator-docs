# `Datatype.EnumItem`

An individual item in an enum.

## Description

The `Datatype.EnumItem` data type represents an individual item in a Roblox
enum.

## Properties

| Property | Type | Description |
|----------|------|-------------|
| `EnumItem.Name` | `string` | The name of the EnumItem. |
| `EnumItem.Value` | `number` | The integral value assigned to the EnumItem. |
| `EnumItem.EnumType` | `Enum` | A reference to the parent `Datatype.Enum` of the EnumItem. |
