# `Datatype.ColorSequenceKeypoint`

A color and time value that represents a keypoint in a
`Datatype.ColorSequence`.

## Constructors

### `ColorSequenceKeypoint.new`

Creates a keypoint with a specified time and color.

**Parameters:**

- `time`: `number`
- `color`: `Color3`

## Properties

| Property | Type | Description |
|----------|------|-------------|
| `ColorSequenceKeypoint.Time` | `number` | The relative time at which the keypoint is located. |
| `ColorSequenceKeypoint.Value` | `Color3` | The Color3 value of the keypoint. |
